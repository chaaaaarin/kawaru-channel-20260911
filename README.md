## 各章の要点

### 1. GPT-6 Astraとは

- 2026年9月3日に発表。ChatGPT の Plus・Pro・Business・Enterprise と API で使える ✅ [OpenAI「GPT-6 Astra」](https://openai.com/index/gpt-6-astra/)
- 一度に読める量（コンテキスト）は 1,050,000 トークン。「いちばん難しい仕事を最初から最後まで任せる」ためのモデル ✅ [OpenAI API モデルページ](https://developers.openai.com/api/docs/models/gpt-6-astra)
- 向かない場面: 使える回数が減りやすい。Codex などで Plus プランを使う場合、5時間あたり5〜45通が目安 ✅ [OpenAI ヘルプ](https://help.openai.com/en/articles/20001516-managing-usage-with-gpt-6-astra-in-work-and-codex)

### 2. Obsidianとは

- 無料のメモアプリ。メモはパソコンの中に Markdown（マークダウン）のファイルとして保存される ✅ [Obsidian 公式サイト](https://obsidian.md/)
- メモ同士をリンクでつなぎ、グラフビューでつながりを見られる。プロパティ（日付・タグの欄）で整理できる
- 向かない場面: 最初は空っぽ。どんなフォルダにするかで止まりやすい

### 3. なぜこの2つを組み合わせるのか

- メモは特定のアプリに閉じないファイル形式なので、Codex で使い始めたボルト（メモの保管庫）を、次に使うAIもそのまま読める ✅ [Obsidian 公式サイト](https://obsidian.md/)
- 「どのAIを使うか」より「どう置いて、どう読ませるか」で結果が変わる。一度整えれば、AIを乗り換えてもそのまま使える
- 向かない場面: メモに書いていないことは、どのAIも知らない

### 4. 裏技①【基本】AIに"自分"を覚えさせる3枚のメモ

- 00_自分 フォルダに「自己紹介」「判断基準」「進行中」の3枚を置く
- Codex は作業の前に AGENTS.md（エージェンツ・エムディー）を読む。そこに「作業の前に 00_自分 の3枚を読む」と1行書いておく ✅ [Codex「AGENTS.md」](https://learn.chatgpt.com/codex/agent-configuration/agents-md)
- 向かない場面: 古いまま置くと、AIも古い前提で動く。進行中は週1回見直す

### 5. 裏技②【公式】Obsidianの社長が配った"AI説明書"

- Obsidian の CEO、Steph Ango（ステフ・アンゴ）さんが GitHub で公開しているAI向けスキル集「obsidian-skills」 ✅ [Obsidian About](https://obsidian.md/about) ✅ [GitHub kepano/obsidian-skills](https://github.com/kepano/obsidian-skills)
- スキルは6つ（Markdown の書き方／Bases（ベース）／Canvas（キャンバス）／Obsidian CLI（シーエルアイ）／Webページの取り込み／テンプレートの一括生成）
- Codex では、標準で入っている `$skill-installer`（スキル・インストーラー）に頼んで入れるか、自分用のスキルの置き場所 `~/.agents/skills` に置く ✅ [Codex「Skills」](https://learn.chatgpt.com/codex/skills)
- 向かない場面: スキルの中身は英語。CLI を使う操作は Obsidian のアプリを起動している間だけ ✅ [Obsidian CLI](https://obsidian.md/cli)

### 6. 裏技③【掘り起こし】過去のメモから、根拠つきで答えさせる

- 日付と案件名を入れて「ボルト内のメモから分かることを教えて。無ければ正直に言って」と聞く
- 答えの根拠になったメモを [[リンク]] で示させる。ボルトに無いことは「情報がない」と答えさせ、推測で埋めさせない
- 一度にたくさん読めるモデルが向く（GPT-6 Astra は 1,050,000 トークン） ✅ [OpenAI API モデルページ](https://developers.openai.com/api/docs/models/gpt-6-astra)
- 向かない場面: 日付や案件名が無い聞き方だと、探す範囲が広がって使う量が増える

### 7. 裏技④【反省メモ】直したことを、次から自動で守らせる

- 「修正が入ったら、会話の最後に reflections.md（リフレクションズ・エムディー）へ反省情報を1件追記する」というルールを最初に渡す
- 書式は「発生日／何が起きたか／なぜ起きたか／次から守ること」の4行。AGENTS.md に「作業の前に reflections.md を読む」と足しておくと、次の会話でも守らせられる
- 向かない場面: 足すだけだと、もう当てはまらないルールも溜まっていく（→ 裏技⑤）

### 8. 裏技⑤【棚卸し】週1回、古くなった記憶を整理させる

- 週1回、reflections.md と 進行中.md を読ませ、「もう当てはまらない反省情報」と「2週間以上動きのない案件」を、理由付きで一覧にさせる
- 削除は、一覧を見て自分が決めてから。AIには勝手に消させない
- 向かない場面: 消すかどうか決めるのは自分。AIが出すのは候補だけ

## プレゼントの中身と受け取り方

1. 🎁 【第二の脳】自動構築キット — AIの質問（最大9問）に答えるだけで、自己紹介・判断基準・進行中の3枚のメモと目次（INDEX.md）の案ができる。毎回説明していた前提をメモに残して、AIに渡せる
2. 🎁 Obsidian × AI トークン節約5点セット — 目次ノート・読む順番・ノートの名札・引き継ぎメモ・節約ルールの5つを、Codex に貼る指示文つきで。必要なメモだけを読ませて、探すための読み込みや説明のし直しを減らす
3. 🎁 AI学習アプリ「HIROGERU」1ヶ月無料クーポン — AIの使い方を基礎から学べるアプリを、1ヶ月無料で使える

受け取りは [プレゼント図書館](https://chaaaaarin.github.io/gift-library/aa/ep/127/) から。動画の概要欄の公式LINEからも案内しています。
